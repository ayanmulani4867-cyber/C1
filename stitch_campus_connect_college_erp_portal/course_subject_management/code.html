target Course Educational Objectives (CEOs)

  • To impart understanding of linear and non-linear abstract data structures, algorithmic complexity, and asymptotic notations (Big O, Omega, Theta).
  • To cultivate proficiency in designing, tracing, and implementing efficient search, sort, tree traversal, and dynamic graph traversal techniques in standard C/C++.
  • To equip students with problem-decomposition instincts required for high-throughput transactional database architectures.

format_list_bulleted Syllabus Unit Breakdown (45 Total Teaching Hours)

6 Standard Units
Unit I: Introduction & Asymptotic Analysis 07 Hours

Space & time trade-offs, Big-O, Omega, Theta notation, recurrence relations, master theorem. Pointers, memory layout, dynamic memory allocation.

Unit II: Linear Structures (Stacks, Queues, Linked Lists) 08 Hours

Singly, doubly, and circular linked lists. Stack operations, recursion management, Polish expressions, circular and priority queues with array & pointer models.

Unit III: Non-Linear Structures: Trees & Binary Search Trees 08 Hours

Binary Tree traversals (Inorder, Preorder, Postorder, Level order). Binary Search Trees (BST), AVL balanced rotations, B-Trees and B+ Trees indexing concepts.

Unit IV: Graph Algorithms & Minimum Spanning Trees 08 Hours

Graph representations: adjacency matrix and lists. BFS, DFS traversals. Prim's, Kruskal's algorithms, shortest paths via Dijkstra's and Bellman-Ford algorithms.

Unit V: Sorting & Hashing Methodologies 07 Hours

Comparison of Quick Sort, Merge Sort, Heap Sort. Hash functions, collision resolution: chaining, open addressing, linear/quadratic probing, and double hashing.

Unit VI: Advanced Algorithmic Paradigms 07 Hours

Dynamic programming basics: 0/1 Knapsack, Longest Common Subsequence. Greedy strategies: Huffman coding. Introduction to NP-Complete vs NP-Hard problems.
